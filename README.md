# FREE RESUME BUILDER (Phase 1: public homepage)

Requires Node.js 18+ (check with `node -v`).

    npm install
    npm run dev          # opens at http://localhost:5173
    npm run build        # production build check
    npm run check:templates   # verifies the 20-template and photo rules

Change the brand name in `src/config/brand.js` and templates in `src/data/templates.js`.
